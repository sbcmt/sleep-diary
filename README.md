# 睡眠日誌 Ver.1.0.5 — Dobhar-chú

© 2021–2026 Dobhar-chú

## 今回の更新

- 承認された緑背景・白い目とグラフのアイコンからiPhoneのホーム画面用アイコン、Android用アイコン（標準・マスク対応）、ファビコンを作成し、`assets/`に格納。
- 承認された文字に閉じた目を組み込んだ「睡眠日誌」テキストロゴを`assets/`に格納し、ヘッダーの文字タイトルと差し替え。
- ホーム画面に追加したときにアプリ名・アイコンが利用されるWeb App Manifestを追加。
- 服薬記録時に **半錠（0.5錠）・1錠・2錠・3錠・4錠** を選択可能。日付・時刻・薬名に紐づけてFirestoreの`users/{uid}/days/{日付}`の`markers`内へ`tablets`フィールドを保存。
- 当日の服薬記録一覧、月間表での各記号のツールチップに薬名と錠数を表示。PDFには1つの時刻に薬が1種類の場合だけ◎の横付近に小さく錠数を表示。
- 同じ時刻に異なる薬を記録可能。同じ時刻・同じ薬を再登録した場合は錠数を更新。記号の削除は従来どおり。
- **旧データ互換**：`tablets`を持たない以前の服薬記録はそのまま保持し、「錠数未登録」として表示。錠数を自動で「1錠」に補完しない。

## GitHub Pagesへ反映するファイル

リポジトリ`https://github.com/sbcmt/sleep-diary`のルートへ、以下をまとめてアップロードしてください。

- `index.html`
- `styles.css`
- `app.js`
- `assets/`フォルダ（中身すべて。追加した画像と`site.webmanifest`を含む）
- `.nojekyll`（既存ファイルがあればそのままで可）

`README.md`は任意です。FirebaseのSecurity Rulesは本更新では変更不要です。

## 動作確認

1. iPhone Safari「ホーム画面に追加」で緑アイコン表示。
2. Android Chrome「ホーム画面に追加」で緑アイコン表示。
3. ログイン画面・ログイン後ヘッダーでテキストロゴ表示。
4. 服薬で薬名、錠数（0.5、1～4錠）を選び登録、同日に再表示・再読み込み後維持。
5. 同じ時刻・同じ薬の再登録で錠数変更／異なる薬は両方保存。
6. 記号削除、睡眠・食事・体重・PDF、既存データの維持。

※ アカウント・健康情報を扱うため、Firebase実環境での権限・機能テストが完了するまで実際の医療データは入力しないでください。プライバシーポリシーやデータ削除等は正式公開前に別途整備が必要です。
