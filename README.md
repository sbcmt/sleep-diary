## 更新内容（2026年11月3日）

- **就寝：▽／起床：△**に統一。月間表・記録画面・当日の記号一覧・表の見方・A4横PDFすべて同一の意味。Firestoreの`bed`/`wake`内部データは変更なし。
- 食事□・服薬◎は任意の30分枠に登録可能。食事と服薬の時間は、アプリが自動で毎日同じ時刻に補完することはありません。必要な日に利用者が記録します。
- 服薬錠数（半錠・1～4錠）、体重（0.1kg）、眠気、出来事、ユーザー設定、12テーマ、印刷・PDFは継続対応。
- **「睡眠分析」を「分析」に改称**。期間は日次／週次／月次、表示は両方／睡眠のみ／体重のみ。
- 睡眠：横軸＝日付・縦軸＝睡眠時間（時間）の**同色棒グラフ**。体重：横軸＝日付・縦軸＝体重（kg）の**折れ線グラフ**。両方選択時は同一画面に**上下で別グラフ**表示（軸を共有しない）。
- 未記録日は0や推定値で補完しない。日次・週次・月次の既存集計カードと記録一覧は維持。
- 画面全体のスマホ幅対応（Ver.1.0.6修正）と、日付・年月の選択方式（Ver.1.0.4修正）を引き継ぐ。
- iPhone/Androidアイコン・ファビコン・文字ロゴを`assets/`に同梱。緑背景が四辺まである画像（白い四隅なし）。
- `assets/site.webmanifest`：起動先を `/sleep-diary/` に修正。Android用アイコン参照先はマニフェストからの相対パスに修正。
- `index.html`：検索エンジン用title、description、canonical、OGP、構造化データ追加。
- `privacy.html`：個人情報の取扱い案内を追加。内容は**正式公開前に運用・法令面の確認が必要**です。
- `SEO_SETTINGS.md`：Dobhar-chú公式サイトのWEB APPS紹介ページ向けSEO文面を用意（WordPressには自動反映されません）。

## GitHubへアップロード

リポジトリ `sbcmt/sleep-diary` のルートへZIP内の中身を**上書き**してください。

- `index.html`, `styles.css`, `app.js`、`privacy.html`、`assets/`（ディレクトリごと）
- `.nojekyll`（そのまま維持）、`README.md`、`SEO_SETTINGS.md`（任意）

**ZIPファイルそのものをアップロードするのではなく、展開したファイルをアップロード**します。`assets/site.webmanifest`は既存のものと置き換えます。Firebase Authentication・Cloud Firestoreのセキュリティルール・既存のデータ形式に変更はありません。

## 保存先

- `users/{uid}`：名前・最初に表示する月・普段の就寝起床時間・テーマカラー
- `users/{uid}/days/{YYYY-MM-DD}`：睡眠・休息のslots、食事・服薬・就寝起床のmarkers、体重、眠気、出来事
- `users/{uid}/medications/{id}`：薬と服用期間

内部データ`bed`は「就寝▽」、`wake`は「起床△」のまま扱い、過去の登録データを変更しません。

## 実機での確認項目

1. Safari/Chromeでログイン・本人の記録のみ取得できる。
2. 就寝▽・起床△が月間表、入力、当日の記録、PDFで一致する。
3. 食事□と服薬◎を別時刻で登録でき、消去・再読み込み後も正常。
4. 分析3モード×日次・週次・月次の9通りで切り替わる。
5. 棒グラフは全日同色、体重は折れ線。未入力日は0にしない。
6. A4横PDFが30日・31日とも1ページに収まる。
7. ホーム画面に追加したアイコンでアプリ起動（旧アイコンが残る場合は削除して再追加）。
8. スマホ起動直後に画面全体がはみ出さない。
9. メール認証、新規登録、メール変更・パスワード再設定が正常に動く。
